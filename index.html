Applied AI

rag-docs-assistant

A FastAPI service that answers questions over Markdown docs with RAG and cites its sources. Retrieval uses chunking and a funnel (top-8 → score threshold → dedup → top-3) with category filtering.

Input guardrails block prompt injection and mask PII. Confidence-based routing sends medium-confidence answers to a human review queue. Retrieval and answer quality are measured with golden sets, a rubric and an LLM judge.

FastAPI · Chroma · OpenAI · Evals · Docker · pytest

An API that sends support tickets to an LLM and returns structured output (category, urgency, summary), validated with Pydantic. A mock mode keeps development and tests free of API cost.
