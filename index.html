Selected engineering work

01 Kerry Group · Edge security

Stopping disguised bot traffic at the edge

Challenge
A high-traffic domain was flooded by unknown bots that kept rotating their IP, user agent and location, so blocking by any single attribute didn't work.
Approach
I built bot-filter rules in Azure Front Door WAF. A rate-limiting rule catches repeated hits on the same URL, and suspicious requests get a bot challenge first. Anyone who passes gets through, and normal visitors are never challenged.
Result
Requests cut from 36M to 20M per year, saving €150K/year.
  • Azure Front Door
  • WAF
  • Rate limiting
  • Bot challenge
02 CI/CD · Infrastructure as Code

Repeatable cloud deployments

Challenge
Classic, click-configured pipelines and hand-built environments made releases slow and hard to reproduce.
Approach
YAML pipelines (build → UAT → Production) with pre-release checks for PII, disallowed plugins and stray SQL dumps. Terraform provisions App Service with slots, MySQL, Application Insights and Storage. Secrets stay in pipeline variable groups.
Result
+50% pipeline efficiency from the CI/CD transformation, and IaC adopted with Terraform.
  • Azure DevOps
  • GitHub Actions
  • Terraform

  1. L1

    rag-docs-assistant ↗

    A RAG API over Markdown docs. Chunking and a retrieval funnel find the passages; guardrails block prompt injection and mask PII; medium-confidence answers go to a human review queue; quality is measured with golden sets and an LLM judge.

    Support-ticket triage with LLM structured output (category, urgency, summary), validated by Pydantic. A mock mode keeps tests free of API cost.
